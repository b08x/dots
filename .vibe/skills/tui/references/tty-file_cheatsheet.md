### Inject Content into File with inject_into_file (Ruby)

Source: https://github.com/piotrmurach/tty-file/blob/master/README.md

Injects specified text into a file at a particular location, identified by content after or before which the text should be inserted. Regular expressions can be used for matching. The `:force` option controls whether to re-inject if content already exists. `safe_inject_into_file` provides a safer injection mechanism.

```ruby
TTY::File.inject_into_file "filename.rb", "text to add", after: "Code below this line\n"

TTY::File.inject_into_file "filename.rb", after: "Code below this line\n" do
  "text to add"
end

TTY::File.inject_into_file("filename.rb", "text to add", after: "Code below this line\n")

TTY::File.safe_inject_into_file("Gemfile", "gem 'tty'")
```

### Inject Content Before Pattern with TTY::File

Source: https://context7.com/piotrmurach/tty-file/llms.txt

Injects specified content into a file before a given pattern. This method supports injecting text directly or using a block to generate the content. It also offers safe injection which checks if the content already exists.

```ruby
require "tty-file"

# Inject before a pattern
TTY::File.inject_into_file("config.rb", "require 'dotenv'\n", before: "require 'rails'\n")

# Inject using regex pattern
TTY::File.inject_into_file("app.rb", "  # New middleware\n", after: /class Application.*\n/)

# Inject using block
TTY::File.inject_into_file("Gemfile", after: "source 'https://rubygems.org'\n") do
  "\ngem 'tty-file'\ngem 'tty-prompt'\n"
end

# Safe injection (checks if content already exists)
TTY::File.inject_into_file("Gemfile", "gem 'tty-file'\n",
                           after: "gem 'rails'\n",
                           force: false)

# Alternative safe method
TTY::File.safe_inject_into_file("Gemfile", "gem 'tty-file'\n", after: "gem 'rails'\n")
```

### Append Content to File with TTY::File

Source: https://context7.com/piotrmurach/tty-file/llms.txt

Appends content to the end of a specified file. This can be done by providing the content directly or using a block. Safe append functionality is available to check if the content already exists. An alias `add_to_file` is also provided.

```ruby
require "tty-file"

# Append text to file
TTY::File.append_to_file("Gemfile", "gem 'tty-file'\n")

# Append using block
TTY::File.append_to_file("Gemfile") do
  "gem 'tty-prompt'\ngem 'pastel'\n"
end

# Safe append (checks if content already exists)
TTY::File.append_to_file("Gemfile", "gem 'tty-file'\n", force: false)

# Alternative safe method
TTY::File.safe_append_to_file("Gemfile", "gem 'rspec'\n")

# Silent append
TTY::File.append_to_file("log.txt", "Error occurred\n", verbose: false)

# Using alias
TTY::File.add_to_file("notes.txt", "New note\n")
```

### Prepend Text to File - Ruby

Source: https://github.com/piotrmurach/tty-file/blob/master/README.md

Prepends text to a specified file. Supports providing text directly or via a block. An optional `:force` option can prevent prepending if the text already exists. Returns `true` on success, `false` otherwise.

```ruby
TTY::File.prepend_to_file("Gemfile", "gem 'tty'")
```

```ruby
TTY::File.prepend_to_file("Gemfile") do
  "gem 'tty'"
end
```

```ruby
TTY::File.prepend_to_file("Gemfile", "gem 'tty'", force: false)
```

### Replace Content in File (Ruby)

Source: https://github.com/piotrmurach/tty-file/blob/master/README.md

Demonstrates how to replace a specific pattern within a file using TTY::File. This method takes the file path, a regular expression to find the content, and the new content to replace it with.

```ruby
TTY::File.replace_in_file("Gemfile", /gem 'rails'/, "gem 'hanami'")
```
