### Integrate TTY-Screen with Thor CLI

Source: https://github.com/piotrmurach/tty-screen/blob/master/_autodocs/getting-started.md

This example demonstrates using TTY::Screen.width in a Thor CLI application to format output, such as listing items, to fit the available terminal width. It divides the width by three for a three-column layout.

```ruby
require 'thor'
require 'tty-screen'

class MyApp < Thor
  desc "list", "List items formatted for terminal"
  def list
    width = TTY::Screen.width
    items = (1..100).map { |i| "Item #{i}" }
    
    items.each_with_index do |item, index|
      print item.ljust(width / 3)
      puts if (index + 1) % 3 == 0
    end
  end
end
```

### Wrap Text Dynamically

Source: https://github.com/piotrmurach/tty-screen/blob/master/_autodocs/getting-started.md

Wrap long text content to fit within the available terminal width, with support for indentation. This function splits text into lines that do not exceed the specified maximum width.

```ruby
require 'tty-screen'

def wrap_text(text, indent = 0)
  width = TTY::Screen.width
  max_width = width - indent
  
  words = text.split
  lines = []
  current_line = ""
  
  words.each do |word|
    if (current_line + " " + word).length <= max_width
      current_line << " " << word
    else
      lines << current_line.lstrip
      current_line = word
    end
  end
  
  lines << current_line.lstrip unless current_line.empty?
  
  indent_str = " " * indent
  lines.map { |line| indent_str + line }
end

long_text = "Lorem ipsum dolor sit amet, consectetur adipiscing elit..."
puts wrap_text(long_text, 4).join("\n")

```

### Test Terminal Formatting with Mock Environment

Source: https://github.com/piotrmurach/tty-screen/blob/master/_autodocs/getting-started.md

This example shows how to test layout formatting based on terminal width using Minitest and by mocking the environment variables that TTY-Screen uses to determine terminal size. This allows for reproducible tests.

```ruby
require 'tty-screen'
require 'minitest/autorun'

describe "Layout" do
  let(:original_env) { TTY::Screen.env }
  
  after do
    TTY::Screen.env = original_env
  end
  
  it "formats for narrow terminal" do
    TTY::Screen.env = {"COLUMNS" => "80"}
    result = format_layout
    assert_match /compact/, result
  end
  
  it "formats for wide terminal" do
    TTY::Screen.env = {"COLUMNS" => "200"}
    result = format_layout
    assert_match /expanded/, result
  end
end
```
