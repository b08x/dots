### Check Executable Existence with TTY::Which.exist?

Source: https://context7.com/piotrmurach/tty-which/llms.txt

Checks if an executable exists in the PATH and returns a boolean value. This is a convenient method for simple existence checks without requiring the full path. It can also search within specified directories.

```ruby
require "tty-which"

# Check if ruby is available
TTY::Which.exist?("ruby")
# => true

# Check for a command that doesn't exist
TTY::Which.exist?("nonexistent_command")
# => false

# Check in specific directories only
TTY::Which.exist?("python", paths: ["/usr/local/bin", "/usr/bin"])
# => true

# Practical example: conditional execution based on available tools
if TTY::Which.exist?("docker")
  system("docker build -t myapp .")
else
  puts "Docker is not installed. Please install Docker first."
end

# Check multiple dependencies
%w[git ruby bundler].each do |cmd|
  unless TTY::Which.exist?(cmd)
    abort "Required command '#{cmd}' not found in PATH"
  end
end
puts "All dependencies found!"
```

### Find Executable Path with TTY::Which

Source: https://github.com/piotrmurach/tty-which/blob/master/README.md

Searches for an executable file in the system's PATH and returns its absolute path if found, otherwise returns nil. This method can also search for a specified absolute path directly.

```ruby
require "tty-which"

TTY::Which.which("less")  # => "/usr/bin/less"
TTY::Which.which("git")   # => "C:\\Program Files\\Git\\bin\\git"
TTY::Which.which("/usr/bin/ruby")  # => "/usr/bin/ruby"
```

### TTY::Which

Source: https://context7.com/piotrmurach/tty-which/llms.txt

As part of the TTY toolkit, this gem enables Ruby applications to reliably find executables regardless of the underlying operating system. It handles Windows-specific concerns like `.exe`, `.bat`, and `.cmd` extensions through the PATHEXT environment variable, while also supporting Unix systems where executables may have no extension. The library can search both the system PATH and custom directories specified by the user.
