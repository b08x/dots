### Message Dashboard Example with TTY::Box

Source: https://context7.com/piotrmurach/tty-box/llms.txt

An example of combining different TTY::Box message types (info, success, warn, error) to create a dashboard-like display in the terminal. This showcases layout capabilities with positioning.

```ruby
require "tty-box"

print TTY::Cursor.clear_screen

# Create a dashboard with all message types
puts TTY::Box.info("Deploying application", top: 2, left: 2)
puts TTY::Box.success("Tests passed", top: 2, left: 29)
puts TTY::Box.warn("Memory usage high", top: 8, left: 2)
puts TTY::Box.error("Build failed", top: 8, left: 29)

puts
```

### Create Info Box with TTY::Box

Source: https://context7.com/piotrmurach/tty-box/llms.txt

Demonstrates how to create basic, positioned, and custom-width info boxes using TTY::Box.info. This is useful for displaying general information or status updates.

```ruby
require "tty-box"

# Basic info box
box = TTY::Box.info("Deploying application")
print box
# Output:
# ╔ ℹ INFO ═══════════════╗
# ║                       ║
# ║ Deploying application ║
# ║                       ║
# ╚═══════════════════════╝

# Positioned info box
box = TTY::Box.info("Deploying application", top: 2, left: 2)
print box

# Custom width info box
box = TTY::Box.info("System update available", width: 40)
print box
```

### Create Error Box with TTY::Box

Source: https://context7.com/piotrmurach/tty-box/llms.txt

Demonstrates the creation of error messages using TTY::Box.error. These boxes use a red background and an error icon, suitable for highlighting critical failures.

```ruby
require "tty-box"

# Basic error box
box = TTY::Box.error("Deploying application")
print box
# Output:
# ╔ ⨯ ERROR ══════════════╗
# ║                       ║
# ║ Deploying application ║
# ║                       ║
# ╚═══════════════════════╝

# Positioned error box
box = TTY::Box.error("Connection failed", top: 8, left: 29)
print box

# Error with additional context
box = TTY::Box.error("Failed to connect to database\nError code: 1045\nAccess denied")
print box
```

### TTY::Box > Summary

Source: https://context7.com/piotrmurach/tty-box/llms.txt

The TTY::Box gem is highly effective for creating structured terminal user interfaces. It's particularly useful for applications that need to display status updates, notifications, menu systems, dialog boxes, or even complex dashboard layouts with multiple distinct panels. The library's strength lies in its ability to create both simple, standalone boxes and intricate arrangements of boxes with precise placement on the terminal screen.

### TTY::Box > Summary

Source: https://context7.com/piotrmurach/tty-box/llms.txt

TTY::Box integrates seamlessly with other TTY gems to build sophisticated terminal applications. For dynamic layouts that adjust to terminal window size, it can be combined with `tty-screen`. For advanced cursor manipulation required in interactive interfaces, `tty-cursor` is a valuable companion. Furthermore, `tty-prompt` can be used alongside TTY::Box to gather user input within styled prompts. This interoperability allows developers to compose rich terminal experiences efficiently, leveraging sensible defaults for rapid development or extensive customization for unique UIs.
