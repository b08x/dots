### Create Tree with DSL (Ruby)

Source: https://context7.com/piotrmurach/tty-tree/llms.txt

Constructs a tree programmatically using a block-based Domain Specific Language (DSL). The `node` and `leaf` methods define the hierarchical structure. The `render` method then visualizes the created tree.

```ruby
require 'tty-tree'

tree = TTY::Tree.new do
  node "project" do
    node "config" do
      leaf "database.yml"
    end
    node "app" do
      node "models" do
        node "user.rb"
        leaf "post.rb"
      end
      node "controllers" do
        leaf "application_controller.rb"
      end
    end
    leaf "Gemfile"
  end
end

puts tree.render
```

### Create Tree from Hash Data (Ruby)

Source: https://context7.com/piotrmurach/tty-tree/llms.txt

Builds a tree structure from a Ruby hash. Keys represent directory names, and array values represent their contents. The `render` method visualizes this data as a tree.

```ruby
require 'tty-tree'

data = {
  myapp: [
    "Gemfile",
    {lib: [
      "myapp.rb",
      {myapp: [
        "version.rb",
        "cli.rb"
      ]}
    ]},
    {spec: [
      "spec_helper.rb",
      "myapp_spec.rb"
    ]},
    "README.md"
  ]
}

tree = TTY::Tree.new(data)
puts tree.render
```

### Default Directory Rendering with TTY::Tree

Source: https://context7.com/piotrmurach/tty-tree/llms.txt

Demonstrates the default directory rendering format for TTY::Tree. The `render` method can be called with `as: :dir` or `as: :directory` to achieve this output. This format is useful for visualizing directory structures.

```ruby
require 'tty-tree'

data = {
  src: [
    "index.js",
    { components: [
      "Header.jsx",
      "Footer.jsx"
    ] },
    "utils"
  ]
}

tree = TTY::Tree.new(data)

puts tree.render(as: :dir)
# =>
# src
# ├── index.js
# ├── components
# │   ├── Header.jsx
# │   └── Footer.jsx
# └── utils

puts tree.render(as: :directory)
# =>
# src
# ├── index.js
# ├── components
# │   ├── Header.jsx
# │   └── Footer.jsx
# └── utils
```

### Create TTY::Tree using DSL

Source: https://github.com/piotrmurach/tty-tree/blob/master/README.md

Illustrates the use of a Domain Specific Language (DSL) to construct a tree structure. The `node` and `leaf` methods allow for a more declarative way to define the tree's content.

```ruby
tree = TTY::Tree.new do
  node "dir1" do
    node "config.dat"
    node "dir2" do
      node "dir3" do
        leaf "file3-1.txt"
      end
      leaf "file2-1.txt"
    end
    node "file1-1.txt"
    leaf "file1-2.txt"
  end
end

```

### TTY-Tree Documentation > Summary

Source: https://context7.com/piotrmurach/tty-tree/llms.txt

TTY::Tree is a versatile tool for command-line applications, particularly useful for visualizing hierarchical data such as file system structures, project scaffolding, dependency trees, or nested configurations. Its string output integrates well with other TTY components like TTY::Prompt for interactive elements and TTY::Pager for handling large outputs, and TTY::Color for adding visual enhancements.
