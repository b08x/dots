### Define Custom Tokens for Dynamic Progress Bar Updates (Ruby)

Source: https://github.com/piotrmurach/tty-progressbar/blob/master/README.md

This snippet demonstrates how to use custom tokens to dynamically update parts of a progress bar's format string. The `advance` method accepts key-value pairs for custom tokens, allowing for flexible content replacement like titles that are not tied to the progress bar's internal state. This is useful for displaying dynamic information alongside the progress.

```ruby
bar = TTY::ProgressBar.new("(:current) :title", total: 4)
bar.advance(title: "Hello Piotr!")
bar.advance(3, title: "Bye Piotr!")
```

### Use Custom Tokens for Dynamic Labels

Illustrates how to pass custom token values to the `advance` method to display dynamic labels, such as filenames or task names, within the progress bar. This allows for more context-specific progress tracking.

```ruby
require "tty-progressbar"

files = ["config.yml", "data.json", "report.csv", "log.txt", "backup.sql"]

bar = TTY::ProgressBar.new("processing :file [:bar] :percent", total: files.size)

files.each do |file|
  sleep(0.3)
  bar.advance(file: file)
end
```

### Create Custom Progress Bar Formatter

Source: https://github.com/piotrmurach/tty-progressbar/blob/master/README.md

Defines a custom formatter class 'TimeFormatter' to dynamically update a ':time' token in the progress bar's format string. It includes the TTY::ProgressBar::Formatter module and implements a 'call' method to substitute the token with the elapsed time.

```ruby
class TimeFormatter
  include TTY::ProgressBar::Formatter[/:time/i]

  def call(value)
    elapsed = (Time.now - progress.start_time).to_s
    value.gsub(matcher, elapsed)
  end
end

bar = TTY::ProgressBar.new(":time", total: 30)
bar.use TimeFormatter
bar.advance
```

### Features > Custom Formatters

Source: https://context7.com/piotrmurach/tty-progressbar/llms.txt

The `tty-progressbar` gem supports custom formatters, enabling you to extend its functionality by adding new tokens. You can create a custom formatter by including `TTY::ProgressBar::Formatter` and defining a matching regular expression pattern for your new token. The `call` method within your formatter class will be responsible for generating the value for this token.
