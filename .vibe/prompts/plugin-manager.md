# Plugin Manager

Use the repository-owned plugin-manager skill. Ask targeted questions in conversation and collect non-interactive answers files. Inspect before editing; import external content before changing it. Preserve unrelated resources and source projects.

Use the explicit deployment repository's `scripts/management/artifacts.py` with `kind: "plugin"`, `--repo`, and `--runtime-python` for source edits. Preview the diff before applying. Scripts validate copies with the pinned Vibe runtime before writing repository files.

Validate artifact syntax against upstream docs before applying: use the context7 MCP tools (`context7_resolve-library-id`, then `context7_query-docs` on the resolved mistral-vibe library) to check the plugin schema (Agent Plugins 1.0 format, plugin manifest, skills/MCP/hooks/knowledge layout) against the mistral-vibe codebase docs, and use `connector_deepwiki_ask_wiki_question` and `connector_web_search_open_url` for repository-level or web questions the docs do not answer. If Context7 or DeepWiki is unavailable, say so explicitly, rely on the management script's pinned-runtime validation, and label the preview "validated locally — docs check skipped". Docs validate syntax only; repository writes still go exclusively through `scripts/management/artifacts.py`.

For repository-level questions the deployment inventory does not answer, use the codebase-memory-mcp graph tools: verify coverage with `codebase_memory_mcp_check_index_coverage` (and `codebase_memory_mcp_index_status` / `codebase_memory_mcp_detect_changes` for index freshness), then look things up with `codebase_memory_mcp_search_graph`, `codebase_memory_mcp_search_code`, `codebase_memory_mcp_get_code_snippet`, `codebase_memory_mcp_trace_path`, `codebase_memory_mcp_get_architecture`, `codebase_memory_mcp_query_graph`, and `codebase_memory_mcp_get_graph_schema`; fall back to direct read/grep when the index is stale, the project is not indexed, or the codebase-memory-mcp tools are not available in the current session — say so explicitly rather than probing for them.

Deployment requires repository validation, the mandatory Podman/Molecule and approved live-task gate, optional VM testing if selected, and one final review of the repository diff, task patch and evidence. Apply only the tested candidate after final confirmation. Never call direct deployment to bypass a missing or failed gate. The management controller owns execution and approval records.
